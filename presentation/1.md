# Tables Memo — Project Description

## What is Tables Memo?

Tables Memo is a structured language learning application built for learners who want to internalize grammar rules — not just memorize isolated words.

The core idea is that language knowledge lives in **patterns**, and the best way to retain patterns is through active recall exercises built around those patterns. Rather than flashcard-style word drilling alone, Tables Memo organizes knowledge around **grammar tables** (conjugation tables, declension tables, etc.) and makes the learner work through every cell of that table using several exercise modes.

---

## Core Concepts

### Grammar Rule Tables
A **Grammar Rule Table** represents one grammar pattern applied to a group of words — for example, "Spanish Present Tense - Regular AR Verbs". The table has:
- **Rows** — the grammatical dimensions (e.g. pronouns: Yo, Tú, Él/Ella, Nosotros, Vosotros, Ellos/Ellas)
- **Columns** — individual base words (e.g. hablar, comer, vivir)
- **Cells** — the correct inflected forms (e.g. hablo, hablas, habla…)

### Base Words
A **Base Word** is any word in its dictionary/canonical form — a verb infinitive, a noun in nominative singular, an adjective in its base gender, etc. When a base word is added to the system, it is associated with the grammar rule tables it belongs to and its cells are generated.

### Vocabulary Topics
Words are also grouped into **Topics** by semantic category — *Food & Drink*, *Family Members*, *Greetings & Introductions*, etc. — independently of their grammar rule. A topic groups words for vocabulary-focused exercises.

### Sentences
Every inflected word form has one or more **example sentences** with a blank where that form fits. Sentences are reused across base words where contextually appropriate. They are categorized by word category and optionally restricted to specific grammar rules or row positions.

## Exercise Modes

| Mode | Description |
|---|---|
| **Fill Cells** | Drag the correct word form into the right table cell |
| **Word Transformation** | Step through insert/delete operations to transform a base word into its inflected form |
| **Sentence Fitting** | Transform a base word in the context of a real example sentence |
| **Multiple Choice Translation** | Choose the correct translation from several options |
| **Typing Translation** | Type the translation from memory |
| **Matching Columns** | Match native words to their translations in two columns |

---

## Target Languages
The initial implementation targets **Spanish**, with an architecture designed to support any inflected language (French, German, Latin, Romanian, etc.).
